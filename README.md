# threat-fusion-dashboard
Real-time multi-source threat fusion dashboard ingesting radar, AIS, and drone telemetry to surface anomaly alerts with confidence scoring.
A defense-oriented situational awareness dashboard that fuses 
simulated radar tracks, AIS vessel data, and drone telemetry 
into a single real-time interface. The system detects behavioral 
anomalies across data streams and surfaces prioritized alerts 
with confidence scores — moving decision-making from raw sensor 
data to actionable intelligence.

Built as a portfolio project targeting defense systems internships.
Stack: Python · FastAPI · React · Leaflet.js · WebSockets
